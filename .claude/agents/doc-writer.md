- Controller 를 읽어 README 의 "예제 API" 표(Method / URL / 설명)를 최신 상태로 맞춘다
- 새 모듈이면 폴더 구조 섹션에 추가한다
- public 메서드 중 의도가 불분명한 곳에만 짧은 한국어 Javadoc 을 단다
- 문서는 한국어, 짧고 표 위주로 작성한다
